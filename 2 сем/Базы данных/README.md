# Базы данных (SQL-задания)

## Описание
Проект содержит набор SQL-скриптов для выполнения практических заданий по теме баз данных (PostgreSQL): создание схем, наполнение тестовыми данными и выполнение запросов.

## Цели и задачи
- Освоить проектирование схем реляционных БД (DDL).
- Научиться наполнять БД данными (DML) и поддерживать связи между таблицами.
- Реализовать требуемые выборки/агрегации/фильтрацию и рекурсивные запросы.
- Оформить решения в виде отдельных файлов по номерам задач.

## Структура проекта
В папке `2 сем/Базы данных` находятся подпапки с отдельными мини-проектами:

1. `1_Транспортные средства`
2. `2_Автомобильные гонки`
3. `3_Бронирование отелей`
4. `4_Структура организации`

## Основные функции/возможности, которые реализованы
- Реляционные связи и ограничения внешних ключей (DDL).
- Агрегации и группировки: `COUNT`, `AVG`, `STRING_AGG`.
- Подзапросы, фильтрация по `HAVING`.
- Рекурсивные запросы с `WITH RECURSIVE` для обхода иерархий сотрудников.

## Запуск и тестирование
Так как проект состоит из SQL-скриптов, запуск выполняется в PostgreSQL в любом клиенте (psql, DBeaver и т.п.).
