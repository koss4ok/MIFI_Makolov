# Telegram-бот викторина: тотемное животное

## Запуск
Требуемая версия Python: рекомендуем **3.12**. На Python 3.13 иногда требуются MSVC build tools (из-за того, что не находятся готовые wheel-ы).

Если у вас только Python 3.13 и вы не хотите менять версию: установите **Build Tools for Visual Studio** (нужно наличие `link.exe` для сборки зависимостей).

 1. Создайте виртуальное окружение:
    - Windows (PowerShell, через Py Launcher): `py -3.12 -m venv .venv`
    - Windows (если `python` уже 3.12): `python -m venv .venv`
    - Linux/macOS: `python3 -m venv .venv`
2. Активируйте окружение:
   - Windows: `.\.venv\\Scripts\\Activate.ps1`
   - Linux/macOS: `source .venv/bin/activate`
3. Чтобы точно поставить зависимости в venv (и не случайно в Python 3.13):
   - `./.venv\\Scripts\\python.exe -m pip install -r requirements.txt`
4. Создайте `.env` из `.env.example` и укажите `BOT_TOKEN`.
5. Запустите бота: `./.venv\\Scripts\\python.exe main.py`

## Команды
- `/start` — начать викторину

## Как определяется результат
Каждый вариант ответа начисляет баллы одному или нескольким животным. После последнего вопроса бот выбирает животное с максимальной суммой баллов (при равенстве берется вариант с “меньшим” id).

## Какие животные есть в викторине
- Дикобраз
- Волк
- Рыжая панда
- Жираф
- Выдра
- Сурикат

## Настройка викторины
Вопросы, варианты и баллы берутся из файла `quiz_config.json`. Чтобы обновить викторину, достаточно изменить этот JSON (и перезапустить бота).
